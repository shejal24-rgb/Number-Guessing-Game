🎯 Number Guessing Game

A fun and interactive command-line game built with Python where players try to guess a randomly generated number within a given range. The game provides helpful hints after each guess, letting the player know whether their guess is 📈 too high or 📉 too low until they find the correct number. 🎉

✨ Features :

🎲 Random number generation for a unique experience every time
💬 Interactive user input and feedback
📈 Hints for high guesses and 📉 hints for low guesses
🔢 Tracks the number of attempts taken
🐍 Built entirely with Python
🚀 Beginner-friendly project for learning programming fundamentals
🛠️ Technologies Used
🐍 Python 3
🎲 Random Module
📚 What You'll Learn
🔄 Loops and iteration
🤔 Conditional statements (if, elif, else)
⌨️ User input handling
🎲 Random number generation
🧩 Basic game logic and problem-solving
🎮 How to Play
▶️ Run the program.
🎲 The game generates a secret number.
🔢 Enter your guess.
💡 Receive feedback:
📈 Too High
📉 Too Low
🔄 Keep guessing until you find the correct number.
🎉 Win the game and see how many attempts it took!
